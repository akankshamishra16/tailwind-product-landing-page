# AuraSound - Wireless Headphones Landing Page 🎧

A modern, clean, and fully responsive product landing page built to showcase frontend fundamentals using *Tailwind CSS utility classes* and *HTML5*.

## ✨ Key Features
- *Responsive Layout:* Designed mobile-first, adapting seamlessly across desktop and mobile using Tailwind's md: breakpoints.
- *Modern UI Aesthetic:* Styled with dark mode theme using Slate and Indigo color palettes.
- *Core Components:* 
  - Sticky Navigation Bar with CTA button
  - Hero Section with product badge and CTA buttons
  - Feature Grid displaying key product specifications
  - Prominent Pricing Card layout

---

## 🛠️ Tech Stack & Utilities Learned
- *HTML5:* Semantic layout structure (<nav>, <section>, <footer>).
- *Tailwind CSS (via CDN):* 
  - *Layout:* flex, grid, grid-cols-*
  - *Spacing:* p-*, m-*, space-x-*, gap-*
  - *Typography & Colors:* text-4xl, font-extrabold, bg-slate-900, text-indigo-400
  - *Interactivity:* hover:bg-indigo-500, transition
